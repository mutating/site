# Регрессии хэдера статического сайта

## Кнопка рядом с хэдером

`platform-button.spec.ts` добавлен и проверен на реализации до выделения
`SquareButton`. Он использует неизменяемый оригинал из `reference/`, а не
генерирует эталоны из новой библиотеки. Сравниваются полные PNG области хэдера
без масок и допуска: изменение даже одного пикселя проваливает тест и сохраняет
изображения до/после в отчёте.

Проверяются 26 ширин от 280 до 2560 px, обе темы и локализации, обычное состояние,
наведение, нажатие, клавиатурный фокус, сочетание фокуса с наведением и sticky-хэдер
над содержимым при прокрутке. Дополнительные 16 сценариев проверяют DPR 2.
Обычные тесты Chromium фиксируют размеры кнопки и SVG, центрирование, отступ от
хэдера, доступное имя, настоящий переход по клику и клавиатуре.

```sh
npm run test:site:header -- platform-button.spec.ts
```

Конечная матрица покрывает все адаптивные режимы и обе стороны брейкпоинтов;
она не перебирает каждую возможную ширину экрана. Для нового брейкпоинта
нужно добавить его ширину и соседнюю в `widths`.

```sh
npm ci
npx playwright install chromium firefox
npm run test:site:header
tests/site/.venv/bin/python -m pytest tests/site/header/test_behavior.py -n 2
```

Нужен Hugo Extended 0.164.0. Скриншоты снимаются в Firefox из закреплённого
Playwright 1.64.0; высокая контрастность дополнительно сравнивается в Chromium.
Поведение проверяется существующим Python Playwright в Chromium.
Обе проверки включены в CI.

## Неизменяемый эталон до переноса

`reference/` содержит HTML главной на EN/RU, CSS, JavaScript и используемые хэдером
ресурсы исходного сайта. Снимок сделан **до изменения его реализации** командой
`node tests/site/header/freeze-reference.mjs`. Коммит и SHA-256 каждого файла
записаны в `reference/manifest.json`; сервер тестов проверяет эти суммы.
Команда отказывается перезаписывать существующий эталон.

На каждом прогоне реальный собранный сайт и сохранённый оригинал открываются
в одном браузере. Одинаковые часы, координаты курсора и моменты CSS-анимаций
дают воспроизводимые пары PNG. Требуется побайтовое равенство: без масок,
допуска на пиксели и скрытия глаза или текста. Эталонный рендерер позволяет
выполнять это сравнение на macOS и Linux без замены PNG из-за различий ОС.
При расхождении отчёт сохраняет снимки «до» и «после» в `test-results/`.
Для точечного разбора можно повторить нужный сценарий с `--trace on`, например:
`npm run test:site:header -- --grep 'rest en light 1440' --trace on`.
Постоянная запись полного DOM во время всех анимаций отключена, чтобы прогон
не создавал гигабайты временных трассировок.
Тесты библиотеки также используют этот сохранённый оригинал.

Фреймы WebGL заменяются пустыми документами: они не входят в хэдер и не должны
менять его фон от прогона к прогону. Разметка, CSS и JavaScript самого хэдера
работают без подмены. Для обычных e2e протокол взаимодействия глаза с настоящим
iframe отдельно проверяет `test_header_eye_tracks_pointer_inside_tentacle_iframe`.

## Скриншотная матрица

- 19 ширин от 280 до 1440 px, включая обе стороны всех границ адаптивности;
  обе темы и EN/RU: 76 состояний покоя.
- 9 ширин (1440, 1120, 1040, 921, 920, 580, 480, 360, 280), обе темы и EN/RU:
  последовательности движения курсора и управления.
- Отдельные последовательности с reduced motion на 1440, 1120 и 360 px.
- Отдельные последовательности настоящего клавиатурного ввода и `:focus-visible`
  на 1440, 1120 и 360 px, в обеих темах и локализациях. Они включают наведение
  на summary языка и переход к его опциям с клавиатуры.
- Курсор в четырёх углах, в центре страницы, в центре и у четырёх краёв глаза,
  на каждой букве T/M/C и у правого края зарезервированной области логотипа.
- Промежуточные кадры пружины взгляда, раскрытия и складывания текста;
  фокус с клавиатуры, наведение на каждый пункт меню, язык, тему и платформу.
- Открытые мобильное и языковое меню, наведение на их ссылки, переключение темы
  с морганием, прокрутка и возврат цвета глаза при наведении, автоматическое
  моргание и закрытие глаза перед перезагрузкой главной.

Это 127 сценариев и 1918 пар кадров, каждый из интерактивных сценариев
сравнивает много кадров.
Дополнительно Chromium сравнивает 16 пар кадров высокой контрастности:
375/1440 px, EN/RU, обе темы, покой и клавиатурный фокус. Отдельный Firefox-тест
проверяет удержание Enter до получения логотипом фокуса настоящими клавишами.
Ещё 24 сценария сравнивают 96 пар при изменении наследуемых от body шрифта,
цвета, межстрочного и межбуквенного интервалов: три режима и оба языка.
Всего постоянный набор содержит 160 сценариев, из них 159 визуальных,
и 2030 пар PNG.
Изменение снимка требует отдельного осознанного пересмотра эталона; обычный
запуск тестов никогда не обновляет ожидаемый результат.

В раунде 2 исправлены повторный выбор темы после задержки deferred JS,
прерывание всплытия Escape из языкового списка и потеря годового immutable
кэширования CSS в `/ui/styles/`. Все шесть новых регрессионных сценариев
воспроизвели проблемы до исправлений; после них пройдены 69 проверок хедера и
темы. Реальный nginx подтвердил 200, immutable и gzip для всех трёх стилей;
deploy smoke теперь проверяет каждый fingerprint CSS. Также прошли 31 проверка
поведения библиотеки, четыре проверки пакета, типы и синтаксис Ansible/bash.
Визуальный аудитор проверил ещё 144 пары в Firefox/Chromium/WebKit, включая
печать, отказ шрифтов, увеличенный текст и zoom 150%. Контрольные сравнения
оригинала с самим собой исключили шум сглаживания границ и маски глаза.

В раунде 3 восстановлен порядок подключения темы и языка до анимаций бренда,
а создание scoped ResizeObserver сделано ленивым. При отсутствующем или
падающем API сохраняются те же ранее работающие контролы и обработчики
указателя wordmark, что у оригинала. Восемь регрессионных сценариев прошли;
независимый аудитор подтвердил результат в Chromium, Firefox и WebKit.
Дополнительно совпали 18 сценариев ввода (300 промежуточных состояний),
164 HTML-хедера, 24 браузерных интеграционных сценария и production build
из изолированного дерева. Визуальный аудит сравнил 462 пары и 198 контрольных
повторов; оставшиеся подозрения исключены прогоном WebKit без подмены часов.

В раунде 4 убрана новая обязательная зависимость обработчиков от AbortController
и signal, восстановлены исходные этапы инициализации всего сайта, исходная
семантика кнопки темы и наследование типографики от body. Сайт монтирует
контролы, затем изображения и ticker, затем бренд и остальные визуализации,
а мобильное меню — на прежнем месте. Общий mount библиотеки позволяет выбрать
эти этапы явно. Все 17 новых поведенческих сценариев воспроизвели проблемы до
исправлений; после исправлений прошли 94 проверки хедера и темы, 24 новых
скриншотных сценария (96 точных пар), 37 проверок поведения библиотеки и четыре
проверки пакета. Одна hover-проверка штатно пропускается на touch.

В раунде 5 найден дополнительный дефект React-адаптера: новая ссылка после
изменения `language.options` закрывала список языков, но оставляла мобильное
меню открытым. Эффект Header теперь обновляет обработчики и при изменении
этого массива. Регрессия проверяет добавление, удаление и повторное добавление
языка на 1040 и 360 px; обе проверки падали до исправления и прошли после.
Эта находка также обнуляет счётчик чистых раундов, хотя статический сайт не
обновляет конфигурацию через React.

Полная проверка после раунда 5: 454 обычных теста сайта, три проверки с
настоящими WebGL iframe, 160 сценариев основной скриншотной матрицы (2030 пар
PNG без допуска), 133 браузерные проверки библиотеки и четыре проверки пакета
прошли. Одна библиотечная hover-проверка штатно пропущена для touch. Также
прошли TypeScript, production Hugo build, синтаксис Ansible/bash и проверка
всех восьми SHA-256 файлов замороженного эталона.

В раунде 6 дополнительно исправлено обновление `LanguageSwitcher.current`:
при неизменном массиве языков React создавал новую ссылку без обработчика
сохранения выбора. Текущий язык теперь входит в зависимости эффекта. Две
новые проверки воспроизвели отказ до исправления, после него прошла вся
функциональная матрица UI: 41 тест и один штатный touch-пропуск.
Второй дефект этого раунда касался замены `renderLink`: новые ссылки роутера
не закрывали мобильное меню. React теперь использует делегирование кликов
по ссылкам; HTML/Hugo сохраняют исходные обработчики на ссылках. Две регрессии
проверяют native → RouterLink → native → RouterLink и сохранение открытого меню
при обычном ререндере с новой inline-функцией. До исправления обе падали.
После обоих исправлений прошли 43 функциональные проверки (один touch-пропуск),
а затем полный набор библиотеки: 137 браузерных проверок и четыре проверки
пакета. Независимый повтор подтвердил 72 выбора языка и 24 перехода по ссылкам.
Визуальный срез этого раунда дал 312 пар с совпавшей геометрией и CSS: четыре
подозрения WebKit остались неподтверждёнными после 104 контрольных пар;
проверка этих состояний продолжается в следующем независимом раунде.

В раунде 7 все четыре подозрения WebKit закрыты: исторические PNG-пары
в точности воспроизвелись при сравнении одной реализации с самой собой,
включая RU с отказом шрифта и настоящими часами. Визуальный аудитор выполнил
312 прямых и контрольных сравнений; поведенческий — 288 DOM/AX-пар и 96
контролей, без подтверждённых расхождений.

Интеграционный аудитор нашёл общий класс несовместимости Hugo и React:
`default`/`with` подменяли явно переданные пустые строки. Это меняло `rel`
и Referer, текст меню, URL бренда, ключ сохранения языка и подпись опции.
Hugo теперь проверяет наличие ключа. Четыре новые браузерные проверки
проверяют реальные cross-origin Referer/document.referrer, перезагрузку
текущего документа, пустые подписи и localStorage с пустым ключом.
Независимая перепроверка всех пяти проявлений в Chromium и Firefox прошла.
