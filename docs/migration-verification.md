# Проверка переноса в монорепозиторий

Дата: 14 октября 2026 года. Проверялся рабочий каталог репозитория `site`; на этапе этих проверок изменения на сервер не применялись. Последующая первичная настройка сервера описана в [инструкции развёртывания](deployment.md).

## Сохранность содержимого

Две независимые сверки списков собранных тестов подтвердили точное совпадение имён, параметров и браузерных конфигураций до и после переноса. При сравнении нормализовались только префиксы каталогов.

| Набор | Тестовых случаев |
| --- | ---: |
| Hugo и сайт | 468 |
| API, миграции и общий запуск | 569 |
| Python-сервис кабинета | 22 |
| Браузеры кабинета | 155 |
| HTTPS кабинета | 1 |
| Визуальные конфигурации | 8 |
| Unit-тесты графика | 2 |

Unit-тесты сохранили исходные проверки; изменился только путь импорта графика.

Повторная SHA-256 сверка подтвердила:

- все 330 файлов исходного `throng_api` из контрольного списка остались неизменными;
- 153 файла Hugo: контент, тема, конфигурация, переводы, скрипты и технические материалы — перенесены без изменения содержимого;
- код API (41 файл), `web/src` (29), `web/public` (17), `web/server` (2) совпадает с исходником;
- все 124 PNG-эталона совпадают с исходными побайтно;
- Python lock-файлы сохранены; общий npm lock сохраняет версии, integrity и записи всех исходных зависимостей.

Генерируемые сборки, окружения, локальные секреты и runtime-данные не включались в перенос исходников.

## Выполненные прогоны

| Набор | Результат |
| --- | --- |
| API, SQLite | Два полных прогона: 569 / 569; первый с покрытием 100% строк и ветвей |
| Сайт | Два полных прогона: по 467 успешных тестов и одному штатному GPU-пропуску |
| Python-сервис кабинета | Два успешных прогона по 22 теста |
| Unit-тесты графика | Два успешных прогона по 2 теста |
| Браузеры кабинета | Два полных успешных прогона по 155 сценариев |
| HTTPS кабинета | Два успешных прогона |
| Визуальные регрессии | Два полных прогона по 8 конфигураций с исходными снимками |

Существующий GPU-пропуск вызывается отсутствием timer queries у Chromium в Linux-окружении; остальные WebGL-проверки выполнялись.

В полном PostgreSQL-прогоне прошли 566 случаев, ещё три завершились `ReadTimeout` при одновременной нагрузке нескольких больших наборов. Все три случая отдельно повторены дважды: оба повтора — 3 / 3. Это дополнительная проверка сохранённых PostgreSQL-тестов; production использует SQLite.

Проверены также сборки Hugo, web и Python-пакета, наличие сертификата и семи миграций в wheel, Ruff, форматирование, D103, синтаксис shell и Ansible, YAML и зависимости CI-job. Старое окружение сайта пересоздано из закреплённых зависимостей без экспериментального pytest-плагина.

## Адаптация тестов

Сохранены все тестовые файлы, фикстуры и проверки. Изменены пути к Hugo, API, кабинету, фикстурам и конфигурации Alembic. Для перенесённых TypeScript-тестов восстановлен исходный ESM-режим через корневое `package.json`.

В проверке завершения процессов включён полный вывод `ps`, поскольку более длинные пути нового дерева обрезались в Linux. SEO-проверка теперь требует общего тестового gate перед деплоем. Для проверки активации добавлена фикстура статической сборки общего релиза.

Таймауты, допуски визуального сравнения и эталонные изображения не менялись. Команды повторения проверок приведены в корневом [README](../README.md).
