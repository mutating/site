# «Как это работает»: рейтинг 60 идей

20 независимых дизайн-агентов предложили по 3 концепта. Оценка: остроумие/элегантность, ясность ценности, компактность. При равенстве — разнообразие визуального механизма и сочетание с hero (не повторять планету и маршруты).

## Итог

Топ-20 выбран после дедупликации близких механизмов: в превью остались разные способы объяснения — трасса, чек, прибор, резервуар, документ, шина, доска, лотерея, коробка, терминал. Это даёт выбор не между оттенками одного макета, а между разными идеями.
