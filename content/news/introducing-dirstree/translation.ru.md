Линтерам, тестовым инструментам и анализаторам кода сначала нужно пройти по директории проекта и решить, какие файлы обрабатывать. Например, выбрать только Python-файлы, но пропустить виртуальные окружения, сгенерированные результаты и служебные данные Git. Если каждый компонент задаёт эти правила отдельно, разные части одной системы могут случайно обработать разные наборы файлов.

[`os.walk()`](https://docs.python.org/3/library/os.html#os.walk) и [`Path.rglob()`](https://docs.python.org/3/library/pathlib.html#pathlib.Path.rglob) выполняют обход, а [PathSpec](https://python-path-specification.readthedocs.io/) обрабатывает шаблоны исключений. Вызывающему коду всё равно приходится объединять их с проверками расширений и оформлять правила для повторного использования.

[dirstree](https://github.com/mutating/dirstree) — небольшая Python-библиотека, которая хранит правила выбора файлов в одном переиспользуемом объекте. Она возвращает подходящие объекты `pathlib.Path` по одному и фильтрует их по расширениям и шаблонам, похожим на правила `.gitignore`. [Релиз](https://github.com/mutating/dirstree/releases/tag/0.0.1) доступен на GitHub.

## Что делает dirstree

Передайте `DirectoryWalker` корень в виде строки или `Path`, при необходимости ограничьте расширения файлов, добавьте исключения в знакомом синтаксисе `.gitignore` — и перебирайте отобранные файлы.

Например, этот обходчик возвращает Python-файлы, исключая метаданные Git и виртуальное окружение:

```python
from dirstree import DirectoryWalker

walker = DirectoryWalker(
    ".",
    extensions=[".py"],
    exclude_patterns=[".git", "venv"],
)

for path in walker.walk():
    print(path)
```

dirstree обходит один корень и возвращает файлы. Он принимает gitignore-подобные шаблоны, но не читает `.gitignore`, не воспроизводит все правила приоритетов Git и не пропускает обход исключённой директории.

## Сравнение с более широкими файловыми инструментами

[WalkDir](https://walkdir.readthedocs.io/en/stable/) добавляет ограничение глубины и фильтры директорий, [PyFilesystem2](https://pyfilesystem2.readthedocs.io/en/latest/reference/walk.html) поддерживает абстрактные файловые системы, а [wcmatch](https://facelessuser.github.io/wcmatch/) — более богатые шаблоны.

dirstree предназначен для меньшего сценария: локальных деревьев исходников, объектов `Path` от входа до выхода и одного места для декларации правил отбора. Он не заявляет превосходство в скорости над стандартной библиотекой и не является универсальным файловым фреймворком.

## Для кого предназначен dirstree

dirstree предназначен для линтеров, анализаторов, инструментов преобразования кода, систем тестирования и сборочных помощников, которым регулярно нужен определённый набор файлов. В более крупной системе он может формировать список работ для другого компонента.
